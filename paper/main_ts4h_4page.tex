\begin{abstract}
Health time-series systems often make sparse temporal decisions: sleep onset,
wake-up, seizure onset, alarms, or episode endpoints.
A common shortcut trains dense segmentation masks and extracts events only after
thresholding, even when the evaluation metric ranks temporal detections.
We propose Boundary Density Likelihood (BDL), a supervised likelihood objective
that converts annotations into expected events per output bin and fits
nonnegative sequence outputs with a Poisson log score.
Unit-sum smoothing represents timing uncertainty without changing the number of
annotated events, and peak decoding yields ranked detections for
tolerance-based average precision.
On sleep-event detection, BDL improves event mAP from 0.575 to 0.680 over
cross-entropy segmentation under matched folds and decoders; at one-minute
tolerance, AP improves from 0.051 to 0.219.
On CHB-MIT seizure detection, BDL improves one-second-stride mAP from 0.287 to
0.388.
The gains survive imbalance, smoothing, and convolutional-backbone controls,
while state-reconstruction analysis clarifies that BDL targets event AP rather
than samplewise occupancy.
\end{abstract}
\vspace{0.4em}
\end{@twocolumnfalse}

\section{Motivation}

Long health recordings are frequently judged by a small set of times.
For sleep monitoring, a many-hour interval is scored through onset and wake-up
matches; for seizure review, clinical utility depends on the timing of episode
boundaries \citep{shoeb2010,goldberger2000,alexander2017,esper2023}.
Modern detection benchmarks reflect this interface: predictions are sorted by
confidence, matched to annotations inside task-specific tolerance windows, and
summarized by precision--recall or average precision \citep{everingham2010pascal,lin2014coco,salles2023}.
Samplewise accuracy can therefore be high while event AP is poor, because late,
early, duplicated, or weakly ranked event times are what the benchmark consumes
\citep{tatbul2018precision}.

The standard reduction expands sparse annotations into dense state labels.
That is the right objective when deployment consumes calibrated labels at every
sample.
It is indirect when the downstream decision is a ranked onset, offset, alarm, or
episode time.
The broader detection literature already uses localized supervision for
keypoints, sound events, action starts and ends, and temporal boundaries
\citep{newell2016stacked,xiao2018simple,phan2015,gao2017turn,lin2018bsn,lin2019bmn}.
The unresolved question is what the localized target should mean after
windowing, smoothing, clipping, and downsampling.
BDL answers this by preserving the event count: each annotation contributes one
event occurrence, and model outputs estimate expected events per bin.

\section{Boundary Density Likelihood}

\caption{BDL preserves one event per annotation through smoothing and binning,

Let $\xseq$ be a time series and let $c$ index a scored event type.
For point events, $c$ is the event label; for interval data, onset and offset
are separate event types.
The annotations define a counting measure
\begin{align}
    \mu_c = \sum_{\tau\in B_c} \delta_\tau ,
\end{align}
where $B_c$ is the collection of annotated type-$c$ event times.
This counting view is standard in temporal point processes, but here it is used
as supervised conditional prediction rather than as a full event-history model
\citep{kingman1993,shchur2021neural}.

Annotation times may be imprecise, so BDL optionally replaces each point with a
nonnegative kernel $\kernel$ satisfying $\sum_r \kernel(r)=1$:
\begin{align}
    y_c(t) = \sum_{\tau\in B_c} \kernel(t-\tau).
    \label{eq:short-smooth}
\end{align}
We use hard, truncated Gaussian, and tolerance-aligned kernels.
Because each kernel has unit sum, smoothing changes where an annotation can
appear but not how many events it represents.
If model bin $b$ covers original timesteps $G_b$, the output target is the
bin-integrated count
\begin{align}
    Y_c(b) = \sum_{t\in G_b} y_c(t).
    \label{eq:short-bin}
\end{align}
Thus downsampling sums expected events into coarser bins rather than averaging
or renormalizing the target scale.

A sequence model outputs logits $z_{\theta,c}(b)$, converted to nonnegative
rates $\rate_{\theta,c}(b\mid\xseq)$ with a softplus parameterization and a
sparse-event prior initialization.
For one bin, the Poisson negative log score is
\begin{align}
    \ell(Y,\rate)=\rate-Y\log\rate ,
\end{align}
omitting the target-only term.
With $\rate_{c,b}=\rate_{\theta,c}(b\mid\xseq)$, the empirical BDL objective is
\begin{align}
    \mathcal{L}_{\mathrm{BDL}}(\theta)
    =
    \sum_c\sum_b
    \left[
        \rate_{c,b}
        -
        Y_c(b)\log \rate_{c,b}
    \right].
    \label{eq:short-loss}
\end{align}
Zero-event windows penalize predicted events, while repeated nearby annotations
can contribute counts larger than one.
The conditional expected risk is minimized when the output equals the expected
number of scored events in each bin, giving the sequence output a fixed unit
rather than an arbitrary proximity or heatmap scale \citep{gneiting2007proper}.
At inference, local maxima in each channel become ranked detections.
For interval applications, alternation or endpoint pairing is a decoder
constraint rather than part of the likelihood.

\section{Experiments}

We evaluate whether aligning the training objective with event AP improves
localization under matched detector choices.
The sleep benchmark contains wrist accelerometer recordings with sleep onset and
wake-up annotations \citep{alexander2017,migueles2019,robbins2019,esper2023}.
It is a direct stress test for the segmentation reduction: the state interval is
long, but scoring uses minute-scale endpoint tolerances.
The CHB-MIT benchmark contains EEG seizure intervals sampled at 256 Hz and
tests a different signal modality with second-scale endpoint tolerances
\citep{shoeb2010,goldberger2000,klem1999}.

All methods are trained as sequence predictors and evaluated as event
detectors.
BDL ranks peaks in learned event-score sequences.
Segmentation baselines predict interval masks and derive event scores from
state transitions.
Within each comparison we hold data splits, backbone, event scorer, and
validation-time post-processing search fixed whenever possible.
Sleep experiments compare BDL-Hard, BDL-Gaussian, and BDL-Tolerance against
cross-entropy, class-weighted cross-entropy, and focal segmentation
\citep{krawczyk2016,lin2017focal}.
Architecture controls repeat the strongest BDL and segmentation objectives with
a bidirectional GRU, a one-dimensional U-Net, and an attention-gated U-Net
\citep{ronneberger2015,oktay2018attention}.
Additional diagnostics test sparse-output prior initialization, tolerance
width, point events, CHB-MIT output stride, and state reconstruction.

\section{Results and Scope}

Figure~\ref{fig:short-sleep} shows the central sleep result.
With the GRU fixed, BDL-Hard reaches 0.680 mAP, compared with 0.575 for
cross-entropy segmentation, 0.544 for class-weighted cross-entropy, and 0.525
for focal loss.
The difference is concentrated where timing is strict: one-minute AP improves
from 0.051 to 0.219, and three-minute AP from 0.283 to 0.530.
At thirty minutes the curves nearly meet, 0.821 versus 0.838, suggesting that
both methods often find the sleep episode, while BDL better ranks localized
endpoints.
BDL-Gaussian and BDL-Tolerance reach 0.660 and 0.605 mAP, so smoothing is not
the entire explanation.
Table~\ref{tab:short-controls} summarizes how the compact controls should be
read.
They are not meant to exhaust detector design; they are meant to reject the
nearest alternative explanations for the main effect.

The architecture controls ask whether this is only a GRU artifact.
Table~\ref{tab:short-summary} shows that BDL-Hard remains above segmentation
for the GRU, U-Net, and attention-gated U-Net when the scorer and decoder
calibration are fixed.
On CHB-MIT, the strongest BDL kernel depends on output stride, but the matched
comparison is stable: BDL-Gaussian improves two-second-stride mAP from 0.252 to
0.360, while BDL-Hard improves one-second-stride mAP from 0.287 to 0.388.
Strict one-to-three-second endpoint analysis preserves the direction for
BDL-Hard and BDL-Gaussian, though the tolerance-shaped kernel no longer helps.

\newpage
\paragraph{State reconstruction.}
This diagnostic makes the complementary point.
When predictions are converted back to sleep-state intervals and scored by
samplewise F1, direct cross-entropy segmentation remains stronger than BDL
hazard reconstruction, 0.914 versus 0.888.
This is the intended scope rather than a contradiction: BDL changes what the
sequence output estimates when the benchmark matches ranked event times, while
state labels remain the direct target when the benchmark measures samplewise
occupancy.

\section{Related Work and Scope}

BDL is closest in spirit to heatmap or proximity supervision, but its output has
a different unit.
A heatmap can be a useful engineering target, yet its scale often depends on
kernel width, pooling, window boundaries, or the number of nearby annotations.
BDL instead asks for the conditional expected number of scored events in each
output bin.
This distinction is small in implementation but important for health time
series, where long empty windows, repeated events, clipped windows, and variable
output strides are common.

The method is also more limited than a temporal point process.
It does not model censoring, a full history likelihood, mark dynamics, or
clinical event generation.
The point-process language is used only to define the supervised quantity that a
sequence predictor should estimate.
This is why the same objective can be used for point events, onset-only labels,
and interval endpoints, while any requirement for legal intervals remains a
decoder or evaluation constraint.

\section{Discussion}

BDL reframes a common health time-series mismatch.
When a benchmark evaluates event times, dense state labels are a convenient but
indirect surrogate; BDL trains the model on expected scored events per output
bin instead.
The likelihood handles empty windows, repeated events, point events, onset-only
labels, and interval endpoints without forcing a paired-interval model.
If a deployment needs legal sleep intervals, duration priors, or calibrated
states, those constraints should be added in decoding or evaluated directly.
This separation is useful for workshop discussion: the method supplies a
statistically defined training signal for event AP, while leaving deployment
constraints, architecture choice, and calibrated state estimation as separate
detector-design questions.

\newpage
\section{Conclusion}

Boundary Density Likelihood addresses a common mismatch in health time-series
detection: models are often trained as samplewise segmenters, but evaluated by
the timing of ranked detections.
It converts annotations into expected events on the model output timeline and
fits the corresponding conditional mean with a Poisson log score.
Across sleep-event and CHB-MIT seizure benchmarks, changing this training
signal improves event AP under matched architectures, folds, and
post-processing.
On sleep, the gain is largest at strict matching tolerances, persists across
multiple backbones, and is not reproduced by segmentation reweighting or
smoothing choices alone.
More broadly, time-discretized sequence models do not have to inherit the
assumptions of samplewise segmentation.
When a health system is judged by ranked event times, its training signal should
estimate the events that will later be matched; when it is judged by per-sample
decisions, state labels remain the direct supervision.
BDL keeps the practical advantages of sequence prediction while making the model
output estimate the temporal detections used by event-level metrics.
